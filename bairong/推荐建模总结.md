# 📌 二分类放款预测模型训练策略

**（仅保留含正样本且样本数>1的用户）**

---

## **1. 业务场景与建模目标**

| 业务任务 | 对同一用户的多个候选产品进行放款概率预测与排序 |
| ---- | ----------------------- |
| 建模目标 | 最大化用户放款规模（数量 / 金额）      |
| 预测对象 | 用户 × 产品 二元组合样本          |
| 标签   | 是否放款（0/1）               |

特点：

* 关注 **用户内排序**，不是跨用户比较
* 存在大量 **纯负用户**（从未放款），对排序训练无贡献
* 排序指标比全局AUC更符合业务效果

---

## **2. 样本选取策略**

| 数据集         | 选择策略                      | 目的                 |
| ----------- | ------------------------- | ------------------ |
| **训练集**     | 仅保留 *样本数>1 且至少含1条正样本* 的用户 | 保证存在有效排序信号，去除无监督样本 |
| **验证集/测试集** | 保留全量用户（含纯负样本）             | 评估泛化能力与实际线上表现      |

📌 数据切分采用**时间滑动窗口（Time Sliding Window）**
Train → Val → Test 连续划分，避免数据泄露。

---

## **3. 建模方案**

### **3.1 特征工程**

| 特征类型     | 示例                    |
| -------- | --------------------- |
| 用户侧画像    | 用户信用、活跃度、历史行为         |
| 产品侧属性    | 利率、额度、期限、产品类型         |
| 交叉特征     | 用户×产品历史交互、偏好类特征       |
| 时间序列特征   | rolling统计、shift、rank等 |
| JSON字段处理 | orjson解析，仅保留必要字段      |

---

### **3.2 训练流程**

1. 模型选择：LGBM / XGBoost / NN
2. 样本：**只保留含正样本且样本数>1的用户**
3. 输出每个 *用户-产品* 的评分
4. 对同一用户候选产品进行排序，推荐Top-K

---

## **4. 评估指标体系**

### **🎯 核心指标：用户内排序效果**

| 指标     | 含义        | 计算对象    |
| ------ | --------- | ------- |
| NDCG@k | 正样本越靠前越高  | 仅含正样本用户 |
| MAP    | 正样本平均排序精度 | 仅含正样本用户 |
| MRR    | 首个正样本排名位置 | 仅含正样本用户 |

> 直接反映推荐效果，最能体现业务收益提升。

---

### **📈 全局指标：泛化能力（参考项）**

| 指标                 | 含义       |
| ------------------ | -------- |
| AUC                | 全局样本区分能力 |
| LogLoss / Brier    | 概率校准能力   |
| Recall / Precision | 辅助监控     |

> AUC下降并不一定代表业务效果变差，因为任务并不关注跨用户比较。

---

## **5. 为什么去掉纯负用户能提升效果？**

### **1️⃣ 噪声样本减少 → 信号更纯净（SNR↑）**

| 用户类型  | 问题                      |
| ----- | ----------------------- |
| 单样本用户 | 无排序结构，无法学习偏好            |
| 全负用户  | 未放款原因可能与模型无关（风控、额度），噪声大 |

🔹 过滤后 → 训练信号更清晰，模型拟合更稳定

---

### **2️⃣ 避免过拟合“无放款群体”**

直接训练全量会让模型学成：

> 都不给放款 = 分数全很低 = 看似AUC高但无收益价值

过滤后：

✔ 正样本比例提高
✔ 排序能力增强
✔ NDCG、GAUC显著提升

---

### **3️⃣ 训练分布更贴合实际推荐场景**

线上是：

> 同用户多产品排序 → 推荐top-K

单样本/纯负用户几乎不贡献收入
去除后训练样本与线上使用分布一致（Distribution Alignment↑）

---

## **6. 折中方案（兼顾排序与AUC）**

📌 先筛选正样本，再按 uid+dt 分组采样负样本，使负样本数量 ≈ 正样本数量

| 方案                | 优点                            |
| ----------------- | ----------------------------- |
| 仅正样本用户训练          | GAUC/NDCG显著提升，但AUC下降          |
| 🔥 ⭐ 折中方案(1:1负采样) | 排序指标提升 + AUC下降可控（最佳trade-off） |

---

## **7. 离线评估结论**

* 模型更关注 **产品区分能力（pid特征）**

* 相比之前依赖用户整体画像 → 模型不再只是区分“好/坏用户”，而是**学会给用户推荐合适产品**

## **7. 线上指标 & 分析**

### **📌 配置及实验结论**

| 项目           | 配置                             |
| ------------ | ------------------------------ |
| **训练样本策略变更** | *使用全部样本 → 仅保留“样本数>1 且含正样本”的用户* |
| **核心线上指标**   | 进件价值 = **收入 / 进件笔数**           |
| **实验人群**     | 老客 **非优质用户层**                  |
| **最终收益结果**   | **实验组收益由 3% → 5%**（相比对照组净提升）   |

---

## **📈 收益提升原因分析**

### **1️⃣ 噪声样本减少 → 信号更纯净（SNR↑）**

| 用户特征              | 影响                     |
| ----------------- | ---------------------- |
| **单样本用户：仅申请1个产品** | 无法反映真实偏好，无排序信号         |
| **全负样本用户：未放款**    | 0/1标签噪声高，可能受额度、风控等外部影响 |

示例对比：

| 用户 | 产品数 | 放款记录  | 标签可信度            |
| -- | --- | ----- | ---------------- |
| A  | 1   | 0     | ❗“未放款”不代表产品差，噪声高 |
| B  | 3   | 1,0,0 | ✔ 可学习高低风险差异      |

🔹 过滤噪声后：

* 模型只学习真正可区分的模式
* 参数拟合稳定性提升
* **预测排序质量显著提高**

📌 结论：**提升训练信号纯度，提高可学习能力**

---

### **2️⃣ 避免模型过拟合于全负样本群体**

全负样本占比可能达 **80%+**。若直接训练：

```
模型最优策略 ≈ 对所有样本预测低分（几乎不放款）
```

| 现象        | 问题            |
| --------- | ------------- |
| AUC 可看似很高 | 但无排序价值，无法带来收益 |
| 分数集中在低区间  | 无区分能力         |
| 线上收益不增长   | 模型学到的是“都别推”   |

过滤非有效样本后：

✔ 正样本占比上升
✔ 模型重心转向**区分收益差异**
✔ 分数区分度变强 → 排序效果提升

📌 结论：**有效避免偏向无放款人群，排序能力增强**

---

### **3️⃣ 训练分布与线上决策场景一致（Alignment↑）**

线上排序流程：

> 用户进入 → 生成候选产品集 → 模型打分排序 → 依次推荐放款

而单样本 / 全负样本：

| 类型   | 问题           |
| ---- | ------------ |
| 单样本  | 无排序可学，无法反映偏好 |
| 全负样本 | 不会贡献收入，训练意义弱 |

🔹 过滤后：

* 训练样本 = 实际排序场景对应人群
* 推理场景与训练分布更加一致
* **收益提升具有稳定可复制性**

📌 关键词：**Train–Inference Distribution Alignment**

---

## **🎯 结论汇总**

| 过滤无效样本的收益  | 对模型带来的效果            |
| ---------- | ------------------- |
| 信号噪声下降     | 📈 学习更稳定、分布更清晰      |
| 训练样本结构更健康  | 📈 避免All-Negative崩塌 |
| 贴合线上真实推理场景 | 📈 排序与收益双提升         |

🚀 最终线上收益从 **3% → 5%**，验证策略有效。
