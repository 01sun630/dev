# 🚀 特征筛选（Feature Selection）指南：目的、方法与实战建议

## 1️⃣ 特征筛选的目的

在模型训练前，去除**冗余**、**无效**或**噪声**特征，以达到以下目标：

* 提高模型**性能**与**稳定性**。
* 减少**过拟合**。
* 提升**可解释性**。

---

## 2️⃣ 特征筛选三大类型

| 类型 | 是否使用模型 | 是否用目标变量($y$) | 示例方法 | 特点 |
| :--- | :--- | :--- | :--- | :--- |
| **Filter**（过滤式） | ❌ 否 | ✅/❌ 可选 | 缺失率、方差、相关系数、IV、卡方、Cramér’s V | 简单快速，**独立于模型** |
| **Wrapper**（包裹式） | ✅ 是 | ✅ 是 | RFE（递归特征消除）、逐步回归 | **精准但耗时** |
| **Embedded**（嵌入式） | ✅ 是 | ✅ 是 | L1正则（Lasso）、树模型重要性（LightGBM/XGBoost） | 训练时**自动完成选择** |

---

## 3️⃣ 常用特征筛选方法

### 🧱 一、无监督筛选（不依赖 $y$）

| 方法 | 说明 | 常用阈值参考 |
| :--- | :--- | :--- |
| **缺失率筛选** | 删除缺失率过高的特征 | **$> 0.95$** |
| **常数/低方差特征** | 去掉方差接近 $0$ 的特征 | 方差 $< 1e-5$ |
| **高相关特征** | 删除强相关冗余特征 | $\approx 0.95$ |
| **高唯一值比例** | 去掉类似 ID 类特征 | 唯一值数 / 总样本 $> 0.95$ |

### 🧮 二、监督式统计筛选（依赖 $y$）

| 方法 | 适用特征类型 | 含义 | 推荐阈值 |
| :--- | :--- | :--- | :--- |
| **IV**（Information Value） | 数值型 / 分箱后变量 | 衡量变量与目标的区分能力 | **IV $> 0.02$** 保留 |
| **卡方检验**（Chi-square） | 离散型 | 检验特征与 $y$ 的独立性 | $p < 0.05$ 显著 |
| **Cramér’s V** | 离散型 | 分类特征与 $y$ 的相关强度 | $> 0.1$ 有效 |
| **Mutual Info**（互信息） | 通用 | 非线性依赖强度 | $> 0.001$ 有效 |
| **KS / AUC** | 连续型 | 模型区分能力指标 | $\text{AUC} > 0.55$ 合理 |

> **🧠 注意：**
> * 统计筛选使用了目标变量 $\rightarrow$ **不能与最终训练样本重叠**（防止信息泄露）。
> * 建议使用**独立样本**（如最近 $7$ 天）进行统计筛选。

### 🌳 三、嵌入式筛选（模型内部自动完成）

| 方法 | 模型 | 指标 | 筛选依据 |
| :--- | :--- | :--- | :--- |
| **Lasso** ($\text{L1}$ 正则) | Logistic/Linear | 权重稀疏性 | 系数 $\neq 0$ |
| **Tree-based Importance** | LightGBM / XGBoost / CatBoost | 信息增益（Gain）/分裂次数（Split） | 重要性累计占比 |
| **Permutation Importance** | 任意模型 | 精度下降幅度 | 排序后选前 $N$ 特征 |

* 🟢 **可与最终训练样本重叠**（因为模型内部交叉验证已防止泄露）。
* 🟢 通常用于最终建模阶段或二次特征精简。

---

## 4️⃣ 推荐特征筛选顺序（Pipeline）

| 阶段 | 方法 | 是否用 $y$ | 样本建议 | 是否可与训练样本重叠 |
| :--- | :--- | :--- | :--- | :--- |
| **① 无监督初筛** | 缺失率、方差、相关性 | ❌ 否 | 全量数据 | ✅ 可以 |
| **② 统计筛选**（监督） | IV、$\chi^2$、Cramér’s V、MI | ✅ 是 | 最近 $7$ 天（筛选集） | ❌ **不可** |
| **③ 嵌入式筛选**（模型） | LGBM / Lasso | ✅ 是 | 最近 $20$ 天（训练集） | ✅ 可以 |
| **④ 稳定性验证** | PSI、WOE 单调、跨时段重要性 | ✅ 是 | OOT 样本 | ✅ 不重叠 |

---

## 5️⃣ 实战推荐阈值总结

| 指标 | 含义 | 推荐阈值 |
| :--- | :--- | :--- |
| 缺失率 | 缺失比例 | $< 0.95$ |
| 相关系数 | 特征间线性相关 | $\approx 0.95$ |
| **IV 值** | 与目标变量相关性 | $\mathbf{IV > 0.02}$ |
| 卡方 $p$ 值 | 独立性检验 | $\mathbf{p < 0.05}$ |
| Cramér’s V | 分类强度 | $> 0.1$ |
| Mutual Info | 非线性依赖 | $> 0.001$ |
| **PSI**（稳定性） | 样本间分布差异 | $\mathbf{< 0.25}$ |
| 累计重要性（LGBM） | 累计信息贡献比例 | 保留至 $\mathbf{0.9–0.95}$ |

---

## 6️⃣ 时间序列建模建议：样本切分原则

| 步骤 | 时间窗口 | 用途 |
| :--- | :--- | :--- |
| **① 筛选样本** | 最近 $7$ 天 | 统计筛选（**防泄露**） |
| **② 训练样本** | 接下来的 $20$ 天 | 模型训练 + 嵌入式筛选 |
| **③ 验证样本** | 更后的几天 | 模型评估（validation） |
| **④ OOT 样本** | 完全未来窗口 | 稳定性与泛化检查 |

> **🧩 原则：**
> **无监督**可重叠，**监督**需隔离；
> **嵌入式**可共用，**验证**必须独立。
